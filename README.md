# Unreal Engine Elective

A first-person shooter prototype made while learning Unreal Engine. The project explores player input, weapons, shooter mechanics and level prototyping.

## What is included

- a first-person character setup;
- enhanced input configuration;
- weapon assets and gameplay setup;
- a shooter variant used for experimentation;
- a small level-prototyping area.

## Opening the project

The Unreal project is located in `UnrealElective_Lvl2/`.

1. Clone or download the repository.
2. Open `UnrealElective_Lvl2/UnrealElective_Lvl2.uproject`.
3. Let Unreal Engine rebuild any generated project data if prompted.

This is a learning project rather than a finished game. It documents my early work with Unreal's first-person workflow and Blueprint-based prototyping.
